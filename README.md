# ExpertMesh

开源、多模型供应商的通用 Agent。用简洁的对话界面完成资料整理、写作和代码分析，复杂任务可以交给多个独立助手协作。

当前版本为可运行的 **v0.1 本地单用户版本**，不是之前的示例原型。界面沿用暖白、暖灰与陶土橙的桌面风格，技术说明集中在文档中。

## 快速启动

需要 **Node.js 24+**（使用内置 SQLite）、npm 和现代浏览器。Windows、macOS、Linux 使用相同启动命令。

```sh
npm install
npm run dev
```

打开 **http://127.0.0.1:5173**，点击“连接模型”或“设置 → 添加服务”，填写自己的服务地址、API Key 和模型 ID。应用不会自带测试模型或虚构的连接状态。

生产方式在一个进程中同时提供前端与 API：

```sh
npm run build
npm start
```

打开 **http://127.0.0.1:3001**。可复制 `.env.example` 为 `.env` 调整配置；开发模式的代理使用固定的 3001 端口。默认只监听本机。

## 使用

1. 添加模型连接。模型显示名称可以自定义；模型 ID 必须来自对应厂商账号或本地安装列表。
2. 开始对话，或选择“执行任务”。可以上传 UTF-8 文本、Markdown、CSV、JSON 和代码文件，每个最大 2 MB。
3. Agent 可以列出、读取、检索授权资料，生成文本或代码文件，委派研究、写作和编程子任务。工具调用需要所选模型支持，并在模型/助手配置中启用。
4. 在任务卡片中暂停、继续或结束工作。进程重启后未完成任务保留为暂停状态，用户可以继续。
5. 从对话或文件页预览、复制、下载结果；在项目内整理资料与对话。助手可自定义名称、要求、默认模型和工具权限。

助手编辑页可以为当前个人空间或项目保存偏好。身份和偏好独立于模型；不同助手、不同项目的偏好分开保存。当前没有自动提取、验证或共享长期记忆。

## 联网搜索

在“设置 → 联网搜索”选择服务、保存并测试，然后在输入框开启“联网”。主助手和协作助手都能搜索与读取网页，回答下方保留来源链接，标明搜索摘要或已读取正文。

- **Tavily**：填写自己的 API Key，默认地址为 `https://api.tavily.com`，使用 [Search API](https://docs.tavily.com/documentation/api-reference/endpoint/search)。搜索会消耗服务额度。
- **SearXNG**：填写自己部署的服务根地址；本机服务需勾选“允许本地搜索服务”。实例须在 `search.formats` 中启用 `json`，参见 [Search API 文档](https://docs.searxng.org/dev/search_api.html)。密钥可选，填写时以 Bearer 头发送给该实例。

每个任务及其子任务合计最多 8 次搜索请求。关闭“联网”时不向模型提供搜索工具。网页阅读仅支持公开 HTTPS 的 HTML/纯文本页面，最多读取 2 MB、返回 30,000 字符，不能读取需登录、JavaScript 渲染或 PDF 的内容；读取失败时模型仍可使用搜索摘要。结果和正文作为不可信资料处理，网页阅读始终拒绝内网地址，且不会向来源网站发送服务密钥。

搜索词会发送给所选服务；系统提示词要求只发送必要关键词，不能保证模型绝不包含用户资料。当前使用本地 HTTP 协议服务验证两种搜索接口、前后端操作及子助手工具调用，未使用真实 Tavily 密钥或真实 SearXNG 实例验证。

## 模型接入

| 服务 | 协议实现 | 当前验证范围 |
| --- | --- | --- |
| OpenAI | Responses API，流式输出、函数调用与无服务端状态续接 | 本地协议测试 |
| Anthropic | Messages API，流式文本与工具调用 | 本地协议测试 |
| Google Gemini | streamGenerateContent，函数调用与签名保留 | 本地协议测试 |
| DeepSeek、阿里云百炼、智谱、自定义兼容服务 | Chat Completions 兼容接口 | 协议测试及本地 HTTP 服务完整流程 |
| Ollama | 原生 `/api/chat` 与 NDJSON 流 | 本地协议测试 |

**没有使用真实付费 API Key 进行各厂商线上验证**。真实模型权限、版本、区域地址、工具能力与协议差异需要使用自己的账号验证。界面不会把适配器存在等同于所有模型都兼容。

连接测试调用模型列表接口，不是收费生成请求；有些兼容服务不提供模型列表，此时可手动配置模型 ID，并通过对话确认。Ollama 要先自行启动服务并下载模型，在连接设置中开启“允许本地或内网服务”。Docker 访问宿主机 Ollama 使用 `http://host.docker.internal:11434`，Linux 需对应 host-gateway 配置。

一次任务保存模型、服务连接、指令与工具配置快照。修改输入区模型只影响新的请求。为某个协作助手明确设置默认模型时，它使用该模型；否则跟随父任务。不会在服务失败后静默切换到另一家厂商。

## 已实现与边界

- 对话与模型输出逐步显示；对话、项目、文件和自定义助手的持久化管理。
- 编辑问题或重新生成回答会创建新的对话版本，保留原对话和结果。
- 文本资料上传、按任务/项目限定的文件工具、产物预览与下载、数据导出。
- 可选联网搜索、公开网页正文读取与来源持久化；主助手和子助手共用任务搜索预算。
- 深度最多一层、最多三个协作子任务；子任务独立消息上下文、身份、偏好与执行记录。
- 每次完整模型轮次和工具结果保存检查点；暂停/取消传播到子任务，恢复复用已完成工具结果。
- 单任务最多 12 个模型轮次；根任务同时最多 3 个。数据库适用于单进程、本地单用户使用。

任意命令执行、电脑控制、MCP、PDF/图片解析、自动记忆治理、多人权限、定时任务与桌面安装包 **尚未实现**。编程助手当前提供分析和代码文件，不能声称已运行测试或修改用户仓库。

## 数据与凭证

数据保存在 `data/`（已加入 Git 忽略）：SQLite 数据库、WAL 文件和本地加密主密钥。API Key 使用 AES-256-GCM 加密，API/前端/导出不会返回密钥。主密钥默认保存在 `data/secret.key`，也可通过 `EXPERTMESH_SECRET_KEY` 设置稳定的 32 字节 base64 值。

备份时需要保留数据库与主密钥；不要只复制数据库，或在未迁移凭证时替换主密钥。在 Windows 上应使用账户文件权限保护数据目录。文件与对话内容目前为本地明文存储，不是全数据库加密。

服务默认绑定回环地址，校验 Host、浏览器 Origin，并禁用跨站 API 请求。自定义模型地址每次请求解析并固定 DNS 结果，拒绝未授权的内网地址，拒绝自动重定向。允许内网服务应只用于自己信任的地址。

这是本地单用户应用，没有登录系统，不适合直接暴露公网。需要远程部署时，应先补充身份认证与授权。删除连接不立即删除已完成任务中的加密配置快照；它用于记录运行配置，仍受本地主密钥保护。

## 开发与检查

```sh
npm run check
npm test
npm run test:e2e
npm run build
```

后端测试覆盖五类协议的流式解析与工具续接、异常流、文件权限、密钥过滤、子助手隔离和重启恢复。浏览器测试通过临时测试服务验证真实前后端调用，不使用付费 API。Windows 默认使用已安装的 Edge；Linux CI 使用 Chromium：

```sh
npx playwright install --with-deps chromium
CI=1 npm run test:e2e
```

PowerShell 可使用 `$env:CI='1'`。测试使用临时数据库，不写入 `data/`，开发服务关闭后再运行浏览器测试（测试占用 3001、5173、3901）。

代码目录：`src/` 为 React 界面，`server/` 为 API/SQLite/模型适配/任务运行时，`shared/` 为数据契约，`tests/` 为协议和端到端测试。

Docker（需要已安装 Docker）：

```sh
docker compose up --build
```

浏览器打开 http://127.0.0.1:3001。Docker 配置作为可选部署方式提供，当前环境未进行 Docker 构建验证。
