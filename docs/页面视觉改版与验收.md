# 页面视觉改版与验收

验收日期：2026-10-10。方向：Claude 式暖纸色、陶土色与留白，结合中文衬线排版和笔记文学气质。

## 已完成的视觉与交互

- 统一浅色、深色的背景、文字、边框、按钮、焦点与状态颜色；完成状态使用独立的鼠尾草绿色。
- 首页采用居中的写作区域；三个灵感入口可填写草稿并聚焦输入框。
- 对话页保留独立滚动区与固定输入框，支持长文本输入、历史阅读位置保持和回到最新消息。
- 项目使用编号目录，助手使用纸张卡片，文件使用阅读清单；设置以六个章节组织。
- 统一弹窗、下拉菜单、Markdown、记忆来源、任务详情和工作区设置的排版。
- 页面与设置章节轻柔进入，弹窗淡入与轻微位移，下拉菜单淡入，按钮图标提供悬停反馈。
- 移动导航支持遮罩、Escape、焦点循环、关闭后恢复焦点；隐藏导航及被遮挡内容不接受键盘焦点。
- 系统开启“减少动态效果”时，关闭动画、过渡与平滑滚动。
- 同步浏览器图标、页面标题和浏览器主题颜色。

## 验证结果

- `npm run build`：通过。
- `npm run check`：通过。
- Playwright：8 项测试通过。
- `npm test`：21 项通过，1 项 Docker 集成测试按项目默认配置跳过（未设置 `EXPERTMESH_TEST_DOCKER=1`）。
- 本次修改文件的 Prettier 检查和 `git diff --check`：通过。

端到端测试使用临时数据库和本地模拟模型、搜索及工具服务；生产页面另做只读访问检查。

运行中的个人数据服务占用 3001 时，可将测试服务放在独立端口：

```powershell
$env:E2E_API_PORT = '3002'
npm run test:e2e
```
