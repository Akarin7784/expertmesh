# 只读 MCP 接入

本次将外部资料工具接入现有任务运行时。工具返回内容作为外部资料，调用和错误进入执行记录；不引入新任务调度器。

## 使用流程

1. 在设置中的“工具连接”添加服务名称、Streamable HTTP 端点、可选 Bearer 令牌。
2. 按服务实际版本选择协议。访问本机或内网服务需明确开启对应选项。
3. 保存并测试连接，读取服务工具目录。
4. 选择助手和空间，选择只读工具，核对实际行为后保存授权。
5. 用支持工具调用的模型执行任务。助手及模型配置均需启用工具。

助手和空间共同限定授权，个人空间单独保存。子助手使用自己的授权。修改连接会清空工具目录和该连接的全部授权；停用连接立即阻止后续调用，重新启用保留既有授权。撤销不能追回已经发出的请求。

## 权限与凭证

工具必须明确声明 `readOnlyHint: true`，且 `destructiveHint` 不能为 true。用户仍需核对工具实际行为。这个实现不能在外部服务上强制只读，建议服务端采用只读凭证或只读账户。

授权保存工具名称及描述、参数定义、注解的哈希。调用前重新获取工具目录，验证哈希，再检查当前授权和连接状态。定义变化停止调用，需重新测试并授权。

Bearer 令牌只在后端解密、发送给指定端点，沿用 AES-256-GCM 存储；API、界面和导出只返回是否已保存。拒绝自动跳转；每次请求重新校验地址并固定 DNS 解析结果。更换含凭证的服务地址需重新填写令牌。

## 协议范围

这是有限的工具客户端，不宣称完整 MCP 规范兼容。

- 2025-11-25：initialize、initialized、会话请求头及会话 DELETE 清理。
- 2026-07-28：无会话 POST，协议版本和客户端元数据、方法/工具名请求头。
- tools/list 分页和 tools/call；支持 JSON、SSE 通知加最终响应。
- 参数使用 JSON Schema 2020-12 校验，也支持明确指定的 draft-07。无法编译、异步定义及请求头参数映射的工具不可授权。
- 文本及 structuredContent 返回模型；不校验服务端输出 schema。

暂不支持 stdio、本地进程、OAuth、GET 订阅、资源/提示模板接口、服务端请求、采样、交互补充输入、自动协议降级和自动重试。图片或其他媒体不能作为唯一结果。

## 限额与中断

一次连接操作或工具调用合计最多 30 秒。响应最多 1 MB，返回模型的结果最多 64 KB，工具目录最多 5 页、100 个工具，单工具参数定义最多 16,000 字符。

任务暂停或结束会中断 HTTP 请求，远端服务是否停止自身工作由服务实现决定。会话清理单独限制为 1 秒；清理失败不覆盖原始结果。失败不会自动重试，已完成工具结果继续沿用任务检查点机制。

## 验证

后端测试验证 JSON/SSE、两种协议请求、参数校验、助手和空间隔离、工具定义变化、撤销、停用、中断、结果限额及凭证过滤。浏览器测试验证保存连接、测试、授权、真实模型协议续接、执行记录和撤销。

验证使用本地 HTTP 协议测试服务，没有完成第三方生产服务互操作测试。

规范参考：[2025-11-25](https://modelcontextprotocol.io/specification/2025-11-25)、[2026-07-28 Streamable HTTP](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http)。
