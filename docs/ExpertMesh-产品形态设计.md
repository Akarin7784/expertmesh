# ExpertMesh 产品形态设计 v0.3

日期：2026-10-09。开源、多供应商、通用 Agent。本文定义目标产品。已按此设计开发可运行的 v0.1，支持持久化对话、资料、项目、助手、多协议接入与协作任务。真实厂商账号尚未验证，已实现范围与后续功能见 [README](../README.md)。原交互原型仅用于设计讨论。

## 定位与外观

用户可以聊天、研究、处理文件、写作与编程，选择自己的模型服务，在对话里跟进工作并获取结果。复杂任务由多个助手协作，用户按需查看分工和贡献。简单请求不必启动完整团队。

延续 Claude Desktop 风格：暖白主区、暖灰侧栏、大留白、柔和圆角输入区和少量陶土橙强调，保留 ExpertMesh 品牌。首页围绕输入与快捷场景，不展示身份、持久化、独立记忆、检查点或调度等原理。技术内容集中在架构文档。

## 信息架构

| 页面 | 功能与动作 |
| --- | --- |
| 对话 | 流式回答、附件、联网、引用、产物、追问；编辑、重试、停止生成、切换模型 |
| 任务 | 进行中/已完成/待处理；查看进展、补充要求、暂停、继续、取消、打开结果 |
| 项目 | 对话、资料、产物与项目说明；创建项目、上传资料、开始项目对话 |
| 助手 | 研究、写作、编程模板与自定义助手；配置名称、指令、模型、工具，导入导出 |
| 文件 | 上传资料与生成产物；预览、下载、引用到对话、删除 |
| 设置 | 模型与服务商、工具连接、外观、数据管理 |

侧栏包含新对话、任务、项目、助手、文件和最近对话；设置在底部。对话输入区包含附件、联网、对话/执行任务模式、模型选择。任务进度以紧凑卡片出现，成员和活动按需展开，结果可直接打开。

## 关键流程

首次使用：添加模型服务 → 选择模型 → 开始对话。允许跳过配置探索界面，发送时再提示完成连接。

任务：输入目标 → 必要时形成简短计划 → 执行 → 查看结果 → 继续修改。系统按任务复杂度组织协作，不要求用户先创建固定四个角色。暂停、取消、重试有独立语义；失败时保留已完成结果并给出下一步。

项目：命名、加入资料或工作目录、写入可选项目说明。后续对话可以使用项目上下文。偏好与项目知识可查看、更正、删除，内部记忆机制不占据一级导航。

助手：名称、用途、指令、可用工具、模型（默认跟随当前选择）；高级参数折叠。助手身份与模型配置分离，更换模型不重新创建助手。任务临时成员和用户保存的助手可清楚区分。

产物：对话内的文件入口打开阅读区域，可修改、查看版本、下载。代码任务显示实际变更和运行结果。没有执行检查时不能标记已验证；示例内容不能称为真实研究结论。

## 多模型产品设计

设置管理服务连接，输入区选择模型。一个厂商允许多个账号、网关或区域连接。

首批目标：OpenAI、Anthropic、Google Gemini、DeepSeek、阿里云百炼/Qwen、智谱/GLM；同时提供 Ollama 和自定义 OpenAI-compatible 入口。后续扩展 OpenRouter、Mistral、xAI 等。此为接入计划，适配和验证完成后才标记支持。

连接配置：服务商、连接名称、API Key、可选地址、模型列表。模型 ID 从接口发现或手动填写，不固定版本。提供连接测试、编辑、默认设置、移除。密钥遮挡，不进入聊天、日志、导出配置或原型状态。

模型选择按连接分组，可收藏常用模型。图片、工具调用等功能根据模型能力显示；不支持时禁用并简短说明。切换影响下一次请求；运行中的任务保留启动配置，用户主动更改在安全边界生效。

工具连接单独管理网页搜索、文件目录、代码执行、MCP 服务。模型供应商不等于工具供应商。不同厂商的协议、价格、能力限制集中在设置与架构中。

## 开源交付范围

首版目标是本地启动的 Web 界面与后端，覆盖对话、附件、项目资料、任务执行/恢复、助手配置、产物预览和多供应商接入。桌面安装包作为后续包装层。用户自带 API Key，也可使用本地模型，不强制注册平台账号。

仓库提供 README、快速启动、示例环境变量、配置说明、适配器规范、贡献指南和许可证。首版已添加 Apache-2.0 许可证与 CI 配置。

语音、电脑控制、在线多人协作、定时任务和社区商店作为后续评估，不在首版承诺中。

## 原型与验收

本版原型覆盖导航、示例对话、任务暂停/继续/结果查看、项目、助手选择、文件预览、模型切换和连接配置。原型不执行模型与工具、不保存密钥、不测试网络，连接状态和产物均为演示。

设计验收：首页无架构说明；核心操作不要求理解子智能体；模型选择和设置一致；任务结果与文件相互可达；明暗主题可读；窄屏无横向溢出。真实实现还需验证各供应商流式输出、工具调用、取消、异常与任务恢复。

参考：[Open WebUI Workspace](https://docs.openwebui.com/features/workspace/)、[本地与云端模型连接](https://docs.openwebui.com/getting-started/quick-start/connect-a-provider/)。借鉴功能组织方式，不声称具备其全部能力。
